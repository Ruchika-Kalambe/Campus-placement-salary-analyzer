# Campus-placement-salary-analyzer
# Campus Placement and Salary Analyzer

## Aim
To analyze campus placement trends and student salary packages using R programming and Shiny.

## Features
- 95% confidence interval for the mean salary package (P3)
- Sampling distribution of mean package (P2)
- Salary prediction using linear regression (P6)
- Chi-square test of independence between branch and placement status (P7)
- Mann–Whitney U test comparing male and female salary packages (P9)

## Technologies Used
- R Programming
- RStudio
- Shiny

## How to Run
1. Install R and RStudio.
2. Install Shiny using `install.packages("shiny")`.
3. Open `app.R` in RStudio.
4. Click **Run App**.

## Dataset
The project uses an illustrative dataset of 24 students. Actual placement data can be substituted for real-world analysis.

## Purpose
This mini-project demonstrates the application of statistical techniques and interactive visualizations to campus placement analysis.
